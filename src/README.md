# src —— 应用源码

四个目录，边界很清楚：**页面只在 `app/`，界面零件只在 `components/`，纯函数只在 `lib/`，数据库只在 `db/`。**

```
app/         页面与接口（Next.js App Router）
components/  界面零件（外壳、组件库、图标）
db/          表结构与 SQLite 连接
lib/         不含 JSX 的纯逻辑与工具
```

放东西的时候先问一句「它会被谁用」：

- 只有一个页面用的界面片段 → 就留在这个页面文件里，别急着抽组件
- 两个以上地方要用的纯函数 → `lib/`，顺手在 `tests/` 加一个用例
- 要碰 SQL → `db/` 提供连接和类型，查询语句仍写在接口里（不建 repository 层）

## 一条硬规矩

`lib/` 里的文件**不 import 任何 React**，`components/` 里的文件**不写 SQL**。这两条守住，逻辑才测得动。

## 值得先看的三处

- `app/page.tsx` —— 今日看板，一个页面把「今天有什么课、谁该续费、谁该跟家长说句话」都摆出来
- `components/ui.tsx` —— 组件库，所有页面的按钮/卡片/弹窗都来自这里，改样式先改它，别在页面里写内联魔法值
- `db/ddl.ts` —— 13 张表的建表语句，加字段要同时想清楚老库怎么补（`ensureColumn()`）
