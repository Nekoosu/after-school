课后服务管理 1.0.0
=================================================

【装成软件（推荐）】
双击同一个文件夹里的「安装.exe」→ 点「开始安装」，几十秒装完。
默认装到 C:\Users\<你>\AppData\Local\课后服务管理，桌面和开始菜单里会出现「课后服务管理」，
以后从开始菜单打开就行，不用再找这个文件夹。
卸载：Windows 设置 →「应用」→ 找「课后服务管理」→ 卸载（或跑安装目录里的「卸载.exe」）；
卸载前它会问要不要把账本先存一份到桌面。
不想装也可以，按下面「一、怎么打开」直接双击 AfterSchool.exe，功能一样，只是没有开始菜单项。

一、怎么打开
-------------------------------------------------
1. 这个文件夹要整个拷走：AfterSchool.exe 和 app 文件夹是配套的，少一个都打不开。
   文件夹本身可以改名（比如改成「课后服务管理」），只要 exe 和 app 的相对位置不变。
2. 双击 AfterSchool.exe，会先冒出一个小块显示「正在启动…」。
3. 几秒后那块自己关掉，弹出一个窗口——**这个窗口就是软件本身**：
   有自己的图标和标题栏，没有地址栏、没有网页标签，任务栏里也是「课后服务管理」。
   窗口可以随便拉大、挪位置、最大化，关掉时记住，下次打开还是这个样子
   （最大化着关掉的，回来也直接最大化）。关了再开，还停在上次看的那一页——
   停在首页就不记，带「?new=1」这类查询串的也不记，免得一开就弹窗。
   万一上次那一页打不开了（比如改过数据库），软件会自己回到首页，不会白屏；
   服务彻底没起来时会给你一页说明和「重试」按钮。窗口顶上的标题跟着当前页面走，
   Alt+Tab 切换时一眼能看出停在哪一页。
4. 想再打开一个？双击同一个 AfterSchool.exe 就行：已经在跑就只把窗口叫到前面来，
   不会开第二份，也不会丢数据。
5. 软件跑在本机 http://127.0.0.1:3210 这个地址上（3210 被占了会自动往后找，
   实际用了哪个记在 app\data\.port），只对本机开放，别人从外面连不进来。
6. 页面觉得小：按住 Ctrl 滚滚轮（或按 Ctrl 加号）放大，Ctrl+0 回到原样，
   放大的比例下次打开也记着。按 F11 全屏看整周课表，再按 F11 或 Esc 退回来。
7. 随时想排课：按 Ctrl+N，直接跳到课表并把「新建」打开；
   按 Ctrl+Shift+N 就是加一个学生；Ctrl+P 打印当前页，Ctrl+F 打开搜索。
   在输入框里打字时不会拦你。
   有活儿在跑（导出、月报这种慢的）时，窗口最上面会有一条细进度条。
8. 第一次打开是 7 天试用，功能一样不少，只是窗口顶上多一条「试用版：还剩 N 天」，
   这条提醒右边就有「填激活码」按钮——不用等到期，随时点开都能填。
    窗口里那串 16 位机器码点「复制」，发到作者邮箱 nekoosu2021@outlook.com，作者回你一个 AS1. 开头的激活码，
   粘进第二个框点「激活」就成（到期后软件自己弹出的窗口，填的是同一张码）。
    一个码最多绑两台电脑（两台机器码一起发到上面那个邮箱就行）；一码一机、换电脑要另要一个码；激活以后不用联网，也不上报任何东西。
   顺带一句：别用浏览器直接开 127.0.0.1:3210，界面能看但列表是空的——
   数据只认软件自己带的那个口令，这是故意的。

二、怎么关闭
-------------------------------------------------
点右上角的 × 不会退出，只是把窗口收进右下角托盘（服务还在跑，随时能叫回来）。
点最小化也一样收进托盘，任务栏不再压着一排。点托盘上的「课」图标（或双击）就回到窗口；
右键托盘图标有：打开主界面 / 今天几节课 / 打开数据文件夹 / 立即备份 / 开机时自动启动 / 退出。
有新版的时候还会多一行「下载新版本 1.0.x」，点一下就用浏览器打开下载页。
设置页的「关于」里也能手动点「检查更新」，还能填一个「检查地址」：
默认查的是作者放在 Gitee 的那份清单（gitee.com/nekoosuu/after-school-updates），
国内网络也能查到；这份清单要是哪天读不到，软件会自己再问一次 GitHub 的发布页。
想换成自己的清单，把 raw 链接填进「检查地址」、保存，再点「检查更新」。
第二行会自己算一句「今天 3 节课（第一节 15:30）· 1 人课时不够 · 2 节该记还没记」，鼠标停在图标上也能看到。
有课忘了记的时候，菜单里还会多一条「去记：数学 · 11-12 15:30」，点一下直接进那一节的记一笔页面。
勾上「开机时自动启动」后，Windows 一开机软件就自己打开（存在注册表 HKCU\...\Run，
卸载或取消勾选即清掉）。要真的退出，用托盘菜单里的「退出」：
它会先把数据写回磁盘、存一份备份，再把后台服务一起停掉。
万一 exe 被任务管理器强杀，下次打开会检测到已有服务并复用它，数据也不会坏。

三、数据存在哪
-------------------------------------------------
全部在你自己的电脑上，不联网、不上传、不需要注册：
  数据库    app\data\app.db
  备份      app\backups\
  运行日志  app\data\server.log
拷给别人或换电脑时，把 app\data 一起带走就是完整的账。

四、备份和恢复
-------------------------------------------------
设置 → 数据 →「立即备份」可以手动存一份；系统每天第一次打开时也会自动存一份，
只保留最近 30 份。每一份后面有三个按钮：恢复、下载、删除。
恢复前系统会先把当前数据另存一份，放心点。
换电脑时：把备份文件放进 app\backups\，再在这里点恢复。

五、说明书在哪
-------------------------------------------------
软件里左侧「使用说明」（共 21 章，含逐页操作速查表），能打印也能存成 PDF。
第一次打开时账本是空的，首页会列出「先做这四件事」：
填机构名字 → 建一门课 → 加第一个学生 → 排一节课，做完一步打一个勾，
全做完它自己就消失；不想看就点卡片右下角「不再显示」。
顶栏几个常用入口：＋ 快速新建（排课 / 记一笔 / 收钱 / 加学生）、
主题（顶栏那个月亮/太阳，点一下就切浅色深色；想跟着 Windows 走，去设置 → 外观）、? 快捷键说明（Ctrl+K 搜索、Ctrl+B 收侧栏）。
设置里还有两样省心的：数据体检（帮你查漏记、重名这类小毛病）、
关于里的新版本检查（有新版会直接给下载链接）；软件每次打开也会自己查一次，
有新版就在右下角弹个小气泡，托盘菜单里同时多一行「下载新版本」，不理它也不影响用。

六、打不开怎么办
-------------------------------------------------
0. 用「安装.exe」装的？先试开始菜单里的「课后服务管理」；免安装的目录被挪走也会打不开。
1. 确认 app 文件夹和 exe 在同一个目录里，没有被拆开。
2. 看 app\data\server.log 的最后几行，通常是端口被占或文件被杀毒软件拦了。
3. 任务管理器里如果还有 AfterSchool.exe 或 node.exe 残留，结束掉再双击。
4. 窗口出来了但是白的：多半是 WebView2 运行时缺了或被安全软件拦了，先在浏览器里打开
   http://127.0.0.1:3210 试试；能打开就说明是窗口的问题，重开一次通常就好。
   1.8.12 起就算页面真的加载不出来，窗口里也会有一页说明和「重试」按钮，不会再是纯白。
5. 数据库坏了别慌：先备份 app\data 整个目录，再从 app\backups 里挑一份恢复。

七、说明
-------------------------------------------------
只监听本机（127.0.0.1），同一个局域网里的其他电脑打不开，这是有意的。
想给别人看某个孩子的情况，用学生详情里的「发给家长」生成只读链接。

需要的组件：Windows 10/11 自带 WebView2 运行时（Win7 要先装一个，微软官网免费下载）。
